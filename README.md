# 跃迁公路 · 一分钟极限挑战

银色跑车通过四点喷射起飞，完成 360° 空翻后垂直落地。避开失控追尾的金棕 MPV、迎面驶来的红色 SUV，以及落在路面上的燃烧电池。

每关 **60 秒**，过关后自动进入下一关，来车速度和频率提高。**任何一次碰撞都立即失败**，随后播放车辆翻倒、零件脱落、火花和起火效果。没有护盾、无敌期或额外生命。

## 上传到 GitHub，让朋友试玩

1. 解压 `aerial-run-one-minute-source.zip`。打开解压后的文件夹。
2. 在 GitHub 新建一个公开仓库，把解压文件夹**里面的全部文件和目录**上传到仓库根目录。根目录必须直接看见 `index.html`，并包含 `.github/workflows/pages.yml`。不要只上传 ZIP，也不要把整套文件再嵌套在另一个文件夹里。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment → Source** 中选择 **GitHub Actions**。
4. 打开仓库 **Actions**，找到 **Deploy Aerial Run to GitHub Pages**。如果首次上传时尚未启用 Pages 导致任务失败，点击 **Run workflow** 重新运行。成功后，Pages 页面和工作流的部署结果会显示可分享的网址。
5. 把 GitHub Pages 的网址发给朋友。分享的是游戏网页地址，不是仓库文件地址。

工作流已随源码提供，无须填写密钥、安装依赖或执行构建。GitHub 项目子路径也能运行，资源使用相对地址。

GitHub 官方参考：[使用 GitHub Pages 自定义工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 在本地试玩

安装 Node.js 20 或更新版本，在这个文件夹打开终端，运行：

```text
node serve.mjs
```

浏览器打开 <http://127.0.0.1:4174>。不要直接双击 `index.html`；浏览器的本地文件限制可能阻止 ES 模块加载。若端口被占用，先关闭另一个本地预览服务，或修改 `serve.mjs` 的端口。

## 操作

| 功能 | 键盘 | 手机 |
| --- | --- | --- |
| 左右转向 | A / D、← / → | 屏幕左下方向按钮 |
| 起飞 / 空翻 | 空格、↑、W | 屏幕右下起飞按钮 |
| 暂停 / 继续 | P、Esc | 右上暂停按钮 |
| 重新开始 | R | 结算页面重新挑战按钮 |
| 音效 | 右上音乐按钮 | 同左 |

一次起飞自动完成整圈空翻，落地后冷却 0.8 秒。需要松开按键再按下一次，长按不会自动连续起飞。红色地面区域是追尾危险区，橙色落点提示燃烧电池。

## 源码结构

全部游戏源码都已包含，可直接修改，不依赖 ChatGPT 登录、Sites 服务或外部 CDN。

```text
index.html                 界面和玩法说明
style.css                  桌面 / 手机布局
game.js                    场景、镜头、输入、音效与界面同步
engine.mjs                 一分钟计时、敌人、碰撞、得分和关卡
sports.mjs                 精细银色跑车的程序化三维模型
models.mjs                 通用建模工具和红色 SUV
mpv.mjs                    金棕 MPV 模型
destruction.mjs            一击即毁动画、碎片、火花、火焰与烟雾
wreck.mjs                  翻倒时的地面支撑高度
vendor/three.module.js     随包提供的 Three.js 0.170.0
vendor/LICENSE             Three.js MIT 许可
serve.mjs                  本地静态预览服务
tests/                     规则、模型和撞毁回归检查
.github/workflows/pages.yml 自动部署 GitHub Pages
```

常用修改入口：`engine.mjs` 中的 `ROUND_SECONDS`、`difficulty()`、起飞时间和冷却常量；`sports.mjs` 中的跑车造型、材质与灯组。

## 检查

无需安装 npm 包。在安装 Node.js 后运行：

```text
npm test
```

检查内容包括：60 秒过关、自动进阶、三种危险物第一次接触就失败、失败后计时和得分冻结、空翻与落地冷却、转向范围、碰撞躲避、碎片落地以及重开恢复。

最高分只保存在每位玩家自己的浏览器里，没有联网排行榜。本版本使用独立的最高分记录。

## 第三方组件

Three.js 0.170.0，MIT 许可证，原许可全文见 `vendor/LICENSE`。模型由几何代码生成，游戏运行不需要额外下载车型文件或图片。

每关最后 20 秒，失控追尾车与电池弹射车的生成间隔缩短至基础间隔的 58%；下一关基础速度和频率继续提高。另有公交、的士、大卡车、洒水车与高空广告牌；所有碰撞一击即毁。广告牌贴地可通过，飞行时需左右躲避。

敌车与普通车互相碰撞后会留下燃烧事故现场，残骸保持在道路原位置，随着驾驶接近后方。主角触碰残骸仍是一击即毁，可转向或起飞避开。侧向姿态喷口随空翻和空中转向点火，带扩散烟雾。

背景音乐 Neon Lift 为 AI 原创程序合成的 136 BPM 电子竞速曲，含鼓组、贝斯、琶音与和弦，无外部音频请求。music.mjs 与乐曲以 CC0 提供，许可见 MUSIC-LICENSE.txt。游戏开始后播放，可独立关闭及调节音量；暂停、切换后台、失败时静音。最后20秒增加节奏层。第1–2关最后20秒双车；第3关常态双车；第4关最后20秒三车；第5关起常态三车。

飞行动作参考第三辆车：水平升空 → 高处悬停 → 快速横向空翻360° → 回正稳定 → 垂直平稳降落。飞行总时长仍为2.25秒，最高5.4米，保留空中转向。喷流改为短促白色气柱，横翻期间左右姿态喷口每0.18秒交替点火。
